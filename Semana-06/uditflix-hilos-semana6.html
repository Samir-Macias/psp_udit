// El salto del monoproceso al multihilo

Mismos cuatro vídeos, mismo trabajo. A la izquierda, el hilo main hace todo solo. A la derecha, cuatro hilos trabajan a la vez y main espera con join(). Las duraciones están simuladas en milisegundos.

Modo secuencial · main hace todo

Cada run() bloquea al hilo main hasta que termina.

for (Transcoder t : jobs) {
    t.run();   // NO crea hilo: se ejecuta en main
}
tiempo total · ~8,2 s0 ms

Modo concurrente · 4 hilos en paralelo

Cada start() abre un hilo nuevo. join() espera a todos.

for (Thread h : hilos) h.start();  // lanza
for (Thread h : hilos) h.join();   // espera
tiempo total · ~3,0 s0 ms
Pulsa el botón y observa quién llega antes a la meta.

Mini-reto A · El espía de estados getState() + isAlive()

Un bucle supervisor en main pregunta cada 500 ms cómo está el worker. Mientras isAlive() sea true, sigue vivo. Cuidado: antes de start() el hilo está en NEW y isAlive() da false.

worker.start();
while (worker.isAlive()) {
  System.out.println(worker.getState());
  Thread.sleep(500);
}
System.out.println(worker.getState()); // TERMINATED

Mini-reto B · Secuencial vs. concurrente medición real

Mide con System.nanoTime() antes y después. Esta demo mide de verdad con el reloj del navegador (performance.now()) las mismas tareas a escala 1:10. No es una animación: el tiempo sale de la ejecución.

long t0 = System.nanoTime();
for (Thread h : hilos) h.run();      // secuencial
long seq = (System.nanoTime() - t0) / 1_000_000;

Mini-reto C · Worker dinámico con ArrayList ArrayList<Thread>

Con 4 hilos puedes escribir cuatro variables. Con 40 necesitas una colección: un bucle crea y arranca, otro hace join(). Cambia N y lanza.

ArrayList<Thread> hilos = new ArrayList<>();
for (int i = 0; i < n; i++) {
  Thread h = new Thread(new Worker(i));
  hilos.add(h);  h.start();
}
for (Thread h : hilos) h.join();

Mini-reto D · Cancelación con interrupt() InterruptedException

interrupt() despierta a un hilo dormido: sleep() lanza InterruptedException. El worker la captura, hace return y pasa a TERMINATED. Limpio, sin matar nada a la fuerza.

public void run() {
  try { Thread.sleep(8000); }
  catch (InterruptedException e) {
    System.out.println("cancelado");
    return;  // sale limpio
  }
}
// en main: worker.interrupt();
